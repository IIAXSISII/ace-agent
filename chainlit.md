# AWS Cloud Engineering Agent 🤖

Welcome to the **ACE Agent** — your AI-powered senior cloud engineer co-worker.

## What I can help with

- 🔍 **Incident Investigation** — Diagnose production issues across CloudWatch, logs, and metrics
- 🏗️ **Infrastructure Changes** — Review and validate CloudFormation changes safely
- 💰 **Cost Analysis** — Identify cost anomalies and optimization opportunities
- 🚀 **Deployments** — Monitor and manage ECS/CodePipeline deployments
- 📊 **Monitoring Queries** — Query metrics and surface anomalies
- 📚 **Knowledge Retrieval** — Search runbooks, architecture docs, and incident history
- 👀 **Code Review** — Review PRs and GitHub Actions workflow runs

## How it works

1. Describe your request in natural language
2. I'll classify your intent and generate an execution plan
3. Review and approve the plan before I take any action
4. I'll coordinate specialized sub-agents and return a verified response

## Example requests

- "Why is the payment service showing high latency in prod?"
- "What's causing the spike in RDS connection errors?"
- "Show me the cost breakdown for the data pipeline this month"
